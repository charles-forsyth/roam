## 🛠️ SPECIFICATION DETAILS:

1. **Config & Garage (`roam.config`):**
   * Support optional `mpg` (or `mpg_normal` / `mpg_econ`) attributes on `VehicleConfig`.

2. **Route Command (`roam.cli:route`):**
   * **`--compare` / `-C` Flag:** Iterate over all vehicles in `load_garage()`, run route calculation once for distance/duration, and render a Rich comparison table comparing travel time, fuel burned, and estimated fuel cost!
   * **`--gas-price` / `-P` Option:** Explicit gas price per gallon (default: $3.99). If `-F gas` is enabled and finds a gas price, auto-use the lowest low-detour gas price found!
   * **`--econ` / `--normal` Flags:** Toggle between Econ mode (44 MPG) and Normal mode (36 MPG) for hybrid vehicles.

3. **DoorDash Command (`roam.cli:doordash`):**
   * New subcommand `roam doordash` to calculate IRS $0.67/mi mileage deductions, gas cost, and net tax shelter gain.
